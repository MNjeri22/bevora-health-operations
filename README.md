# Bevora Health Operations website

This is a static, responsive website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `bevora-health-operations`.
2. Upload everything inside this folder, keeping `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
5. GitHub will provide a `github.io` address.

## Connect a domain

In **Settings → Pages**, enter the domain under **Custom domain**. Follow GitHub's displayed DNS instructions at the domain registrar, then enable **Enforce HTTPS**.

## Contact form activation

The form uses FormSubmit and sends to `admin@bevorahealth.com`. The first submission may trigger a confirmation email. Complete that confirmation before relying on the form. Test the entire flow before launch.

## Important review before launch

- Ask qualified counsel to review `privacy.html`.
- Confirm the business's final U.S. and U.K. service scope.
- Verify all statements about safeguards, confidentiality and readiness services.
- Do not request or accept PHI through the general contact form.
